# How to cite this work

CasMD is currently an **unpublished online toolkit** — no DOI, no peer review yet.

## Recommended citation (plain-text)

```
Zhao, Z., & Hsing, I.-M. (2026). CasMD: an online toolkit for protein–nucleic
acid molecular dynamics simulation. Hsing Lab, Department of Chemical and
Biological Engineering, HKUST. Unpublished.
https://github.com/zzhaobz/CasMD · https://huggingface.co/spaces/zzhaobz/CasMD
Version 0.7.0.
```

## BibTeX

```bibtex
@misc{zhao2026casmd,
  author       = {Zhao, Zibin and Hsing, I-Ming},
  title        = {CasMD: an online toolkit for protein--nucleic acid molecular dynamics simulation},
  year         = {2026},
  howpublished = {Online toolkit, Hsing Lab, HKUST},
  note         = {Unpublished. Version 0.7.0.},
  url          = {https://huggingface.co/spaces/zzhaobz/CasMD}
}
```
